# One Star for Monday

A one-star review of Monday, written as though Monday were a restaurant — 18 words, one line, plain text.

> One star. Monday seated me by the toilets, served cold coffee, and billed me for the entire week.

Built for the make.fun bounty [One Star for Monday](https://make.fun/bounty/u-clever-harbor-75-one-star-for-monday-9ead4a61).

## How it works

`main.py` (stdlib only) writes the single review line to `/output/entry.txt` — no trailing newline, mode `0644`.

```sh
python3 main.py
cat /output/entry.txt
```
